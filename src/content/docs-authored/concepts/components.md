# Components

## What
The raw building blocks of every rig. Components that give your joints life. Create new components using Python.

## Why
If you want more custom control over your rigs, use components and build them up into limbs.

## How
Components don't come with a skeleton or any joints. You add components to joints to give them controls, the simplest example is an FK module which drives a single joint. Each component has its own requirements for how it attaches, so hover over a component in the Palette for the details.
